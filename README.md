Business Analytics Dashboard — Excel

Project Overview

This project showcases an interactive sales dashboard built using Microsoft Excel to analyze business performance, revenue, profitability, and product-level metrics.

The dashboard helps users explore sales performance through key performance indicators (KPIs), summaries, and interactive filters.

Business Objectives

- Monitor overall sales and profitability.
- Track key business performance indicators.
- Compare sales performance across regions and product categories.
- Explore monthly sales trends.
- Retrieve product information using a product lookup tool.
- Support data-driven business decisions through clear visual reporting.

Tools & Skills

- Microsoft Excel
- Data analysis and reporting
- KPI tracking
- Excel formulas and lookup functions
- Interactive dashboard design
- Business performance analysis

Workbook Structure

1. Dashboard
An interactive overview of sales performance, including available KPIs, summary charts, and filters.

2. Sales Data
The sales dataset used for the analysis, containing transaction-level information and sales-related fields.

3. Product Lookup
A product reference sheet for looking up product information, including available pricing, cost, and margin details.

  Key Metrics

The dashboard is designed to help explore metrics such as:

- Total Revenue
- Total Profit
- Profit Margin
- Total Orders
- Units Sold
- Average Order Value

    Business Questions
  
This project can help answer questions such as:
- How does revenue change over time?
- Which regions contribute to sales performance?
- How do product categories compare?
- How does profitability vary across products?
- What are the overall sales and order trends?

How to Use

1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Navigate to the Dashboard worksheet.
4. Use the available filters to explore sales performance.
5. Open Product Lookup to explore product information.

 Skills Demonstrated
 
- Excel-based business analysis
- KPI development and monitoring
- Dashboard building and data visualization
- Structured data presentation
- Translating data into business-focused reporting

Dataset Disclaimer

This project uses sample data for learning and portfolio demonstration. The results should not be interpreted as actual business performance.
